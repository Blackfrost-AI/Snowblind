# Acceptable Use

Snowblind is a defensive OPSEC and anonymity toolkit built for **authorized
security work**: penetration testing, red-team engagements, bug bounty,
privacy research, and journaling/activism on infrastructure **you own or have
explicit written permission to test**.

By using this software you agree that:

1. **You will only use it on systems you own or are authorized to test.**
   Get it in writing. "Authorized" means the system owner said yes — not
   "nobody said no."
2. **You are responsible for compliance** with all applicable laws in your
   jurisdiction (computer misuse / unauthorized-access statutes, export
   controls, sanctions, and any rules set by bug-bounty program scope).
3. **You will not use Snowblind to conceal unlawful activity.** Anonymity is
   a safety property for defenders and researchers, not a cloak for abuse.
4. **No warranty.** The software is provided "AS IS" under the Apache
   License, Version 2.0. The authors and Blackfrost-AI accept no liability
   for how you use it. You are the operator; you own the outcome.

Reports of misuse, or questions about whether an intended use is in scope,
can be raised by opening a private security advisory or contacting the
maintainers.
